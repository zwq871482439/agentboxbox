# 0.4 更新说明

0.4 没动「首领拆活派卡、打工猫干活、首领验收」这一套。这一版主要把几件事做实了：上岗更简单（盒子不再替你改
你 AI 软件里的任何设置）、猫的状态说得更清楚（在跑、闲、歇着、已停用分开，卡排队写清楚在等谁）、断在半路的卡
能接着做、界面能说中英文。办公室画面里也添了几样新道具。

## 上岗更简单

- 盒子不再替你写 AI 软件的配置。0.3 会认出你电脑上的 Cursor / Claude Code / Codex，把连接条目全写进去，
  没在用的也写了。0.4 只登记首领，再给你一段话：首领会按话里的地址直接连上盒子干活；想让它下次更顺手，
  它先问你要不要把盒子加进它的工具列表，你同意了由那个软件里的 AI 自己加（只改自己、先备份、说明改了哪）。
- 首领用哪家 AI 软件按连上时报的名字记，不再猜；你贴那段话时用哪家，工位上就写哪家。
- 贴进 AI 软件的那段话缩成 4 句：身份、先拿上岗说明、没有工具时怎么按地址直接调、盒子没开怎么办。
  其余规则改成盒子每次回话里带的持续提醒，首领不容易忘。
- 招打工猫的窗口收了尾：接口类型从「高级」挪到主表单、跟接口地址同一行、选项说人话，不用先懂；
  额度查询按接口地址自动定；猫等开箱动画放完才出来。
  「测试连接」失败时密钥不丢，填错的说法分得更细（没额度、密钥不对、连不上、没测出来），
  服务商原文收进默认折叠的「详情」里。
- 连不上服务商也能把猫先招进来：派给它的卡会排队，这台电脑连得上接口就自动开工。
- 去掉了内置 Pi 首领，首领只在你自己的 AI 软件里：首页那个「和首领说话」没有了，盒子里也不再有一份
  自己养的首领。
- exe 只开一个：再双击一次，已经开着的那个把窗口弹出来，不会多出第二个托盘图标。
- 工位页的招募和「修改配置」只问必要的：接活方式就两种（用 API key 自动跑 / 会话模式），
  不再问角色、在哪个 AI 软件、密钥变量名、主机名这些你不用管的事；首领那边只能换猫的样子。
- 首领只有一个：再登记一个新首领，是把原来那个换掉（旧的工位删掉、它的密钥也删掉），不会变成两只首领。
- 招打工猫时存的是模型 id，模型名、上下文长度、最大输出跟着模型自动填好，你不用抄。
- 工牌上的「复制」：名字末尾是数字就接着往上数（打工猫2 复制出来是打工猫3），配置和密钥一起复制，工作目录单独开一个。

## 打工猫怎么接活

- 接活方式只有两种：用 API key 自动跑（盒子用 Pi 一张卡起一个进程，做完退出）和会话模式
  （你的 AI 软件每隔几分钟开一个新对话来领卡）。
- 第二种接活方式统一叫「会话模式」：界面、上岗说明、看板都是这一个叫法。
- 会话模式只有文件交换这一种：盒子把卡写进 data/exchange 里的一个文件，猫读完写回报，不分是哪个 AI 软件。
- 卡上写的工作目录要是那个目录不存在，派活当场就拒收并说清楚是哪个路径不对，
  不用等开工失败后才报成「工位不通」。

## 接服务商更稳

- 打工猫照 Pi 自带的设置接服务商：接口地址和模型对得上 Pi 认得的那一家，接口类型、兼容开关、思考档位都照 Pi 的来。
  比如 Kimi 编程套餐要的几个开关、MiniMax M3.1 必须开的「自适应思考」，不用你懂也不用你填。
- 自带的 Pi 升到 1.4.0（认得 MiniMax-M3.1-Flash），版本钉死，不跟着打包机上装的走。
- 服务商新出的模型 Pi 还没收录、回话里又写明要什么开关的，盒子自己记进这只猫的设置：测试连接时再试一次，
  派出去的卡马上重跑，动态里写明改了什么。
- 「测试连接」跟派卡发的是同一种请求（不再关掉思考去测），测过了就是真能干活。
- 测试连接碰上 429：算连上了（地址和密钥都对），只提醒一句服务商这会儿在限流或额度见底，不再说成「这个账号没额度了」。
- 服务商清单里 Anthropic 那种接口的地址末尾带着 /v1 的，表单里自动去掉（Pi 自己会补，留着就请求到 /v1/v1）。
- 卡没跑成时写的原因是服务商的报错原文，不再是 Node 打的一句证书警告。

## 查余量（套餐还剩多少）

- 现在认得三家编程套餐：Kimi Code 会员（接口地址 api.kimi.com）、智谱 GLM Coding Plan（open.bigmodel.cn）、
  MiniMax Token Plan（minimaxi.com / minimax.cn）。工位里填了这几家的接口地址，盒子会自己选好查法，不用你挑。
- 别家可以在工位设置里选「自定义」，填两样：查询地址，和返回结果里已用百分比在哪个位置（路径）。
- 什么时候查，两种选一：每轮跑完查一次，或者每 N 分钟查一次。
- 查到哪儿看：工位详情里写着这一份还剩多少，看板的「用量」里按窗口画小条，办公室里猫头顶有一条余量血条
  （几个窗口里取最卡脖子的那个，已经过了重置时间的不算）。
- 后面会接更多家。

## 猫的状态说清楚

- 工位状态和任务排队分开说。「歇着」带原因和预计回来的时间（额度用完 / 被限流 / 接口连不上 / 服务商出错，
  到点自动回来接着干）；「已停用」只有你手动关掉才会出现；排队写清楚在等谁：等某只猫干完手上这张、等它回来、
  还是等接口连通。
- 一只猫同一时间只干一张卡：又来一张就排队，看板上写「在跑 · 后面排 N 张」。改工位配置不会再误伤
  它正在跑的那张卡。
- 没有按服务商的并发上限了：一只猫就是一路。想同时多跑几张，就多招几只猫，或者点工牌上的「复制」；
  同一个服务商招 3 只猫就能同时跑 3 张卡。服务商限流时靠「歇着（被限流）」兜底——那只猫歇着、卡回排队，
  到点自己回来接着干，别的猫不受影响。
- 开工前被拦下的卡显示「没开工」：不算失败。首领可以重派或撤掉，猫的失败状态也能清掉。
- 首领待办你也能自己清：首领那段对话结束了，待办不会一直挂着——看板上按卡的状态给「通过 / 打回 / 再派一次 / 撤掉」，
  动态里记成你定的；办公室的待办抽屉列出明细，点标题去看板。
- 模型接口出错不算交回、也不算失败：额度用完 / 被限流 / 服务商出错 / 连不上，都不给这张卡记失败。
- 首领的「最近活动」跟着工具调用走、派活站会不重复算猫、顶栏「成功率」只算真跑完的卡。
- 验收人只剩三种：首领自己看、交给用户定、质检过就算完成。原来写着「指定另一只猫交叉验」的那种其实没有自动派卡，
  卡会一直停在首领待办里，0.4 去掉了；想让另一只猫帮着看，首领另派它一张审稿卡就行。

## 断掉的卡能接着做

- 上次退出或崩溃时手里还有活没干完的猫，下次打开首页时弹窗口问你：「全部接着做」（接着上次的对话继续干）、
  「交给首领决定」或「先不管」。不用从头再跑一遍。
- 打工猫干到一半遇上模型接口出错（连不上 / 被限流 / 服务端出错），这张卡不记失败也不丢：猫出去歇着，
  卡回队列等它；猫回来后接着上次的对话继续干。同一张卡这样自动续跑最多三次，还不行才记成「中断」，
  交给你和首领定。
- 核心被强杀或崩溃时，那一轮已经花掉的用量也会补记进账本，不至于凭空少一截。

## 桌面通知

- 首领在你自己那边的软件里，那边的会话闲着时盒子叫不醒它。所以卡交回、没跑成、没开工、卡住、或者等首领拿主意时，
  盒子在桌面右下角弹一条系统通知，提醒你去会话里跟首领说一声。
- 只弹那几件要人管的事：交回、没跑成、没开工、卡住、等首领拿主意。短时间内来好几件会合成一条，不连着弹。
- 不想收就在设置页把「卡交回、出问题时在桌面弹通知」关掉。
- 托盘图标设置只留当前这一条：别的目录里没在跑的猫猫盒子 exe 留下的旧条目一起清掉。

## 中英双语

- 界面、上岗话、办公室画面、自检、托盘和命令行输出都有中文和英文两份。语言第一次打开时按系统语言定，
  欢迎窗口里有个「中文 / English」小开关，当场就能换；以后在设置页的「盒子参数」里也能改。
- 首领和打工猫的上岗说明都有英文版：英文界面下贴给 AI 的那段话、首领的上岗说明、派给打工猫的说明都是英文的，
  打工猫用英文写回报，盒子照样读得懂。
- 许可、第三方声明和隐私声明也有英文版：设置页「数据和隐私」跟着界面语言走，英文版是 `PRIVACY.en.md`
  和 `THIRD_PARTY_NOTICES.en.md`。

## 办公室的新道具

- 聚会街机：会议室投影机旁的桌角上立一台像素街机，点它弹「聚会」菜单——放电影、来一局游戏、或让猫们回去干活。以前的「场景」菜单没有了。
- 昼夜开关挪进画布：霓虹牌正下方一个五档开关（自动 / 清晨 / 白天 / 傍晚 / 夜晚），点开选一档；
  自动档跟本机时间走，时间点在设置页改。
- 「动态」「用量」两个按钮挪进画布：挂在挂钟右边，点开是浮窗，有新动静带红点。首页顶栏下面那行没了。
- 点猫看详情：办公室里点一只猫弹出它的状态、在干哪张卡、排了几张、剩余额度、最近活动。
- 工位页能改配置：换猫样子、改名、换接入方式都在「修改配置」里；招新猫不撞已有猫的样子。

## 临时文件和隐私

- 临时文件统一放程序目录 `tmp\`：每张卡一个子目录，自动清理；没有卡在跑时整个删掉也没事，
  设置页有一键清理。exe 旁边只有三样：软件本体、`data\`（配置和记录）、`tmp\`（过程垃圾）。
- 打工猫不加载你本机的 skills 和提示模板：启动时加 `--no-skills --no-prompt-templates`，
  你给别的 AI 软件装的技能不会被它读、也不会发出去。
- 隐私声明按 0.4 重写（见 PRIVACY.md）：盒子不改你 AI 软件的任何设置、不读你的 skills、没有账号没有服务器。
- 密钥只从 data/secrets.json 来：页面上填的密钥只存在这个文件里，盒子不读你系统里的环境变量当密钥；
  data/pi 里只记盒子自己内部用的变量名，不写密钥本身。

## 发版方式

- 开发仓和发版仓分开：发版仓只放一份干净的源码快照（白名单挑选），不带开发历史，也不带内部信息。
- 出快照前先扫一遍禁词和密钥（`tools/publish_release.py`），扫到就停下来报出文件行号，不往下走。
- 发版仓打一个标签，流水线自动打 exe、算 sha256、把这一版的说明当附件发成 Release。

## 已知问题

- 从 0.2 升上来的：客户端里 0.2 写的连接条目还会拉起已经不存在的旧 exe。自检会标出来；把那条旧条目删掉，
  再按首页「叫醒首领」那段话里的步骤连一次就行（可以让那个软件里的 AI 帮你改，它只改自己、先备份）。
- AI 客户端跑在 WSL 里（比如在 WSL 里用 Claude Code / Codex）时连不到盒子：盒子只听 Windows 本机的 127.0.0.1，
  WSL2 默认的网络连不过来。在 Windows 里直接用客户端没有这个问题。
- 目前只有 Windows 版（Windows 10 / 11，64 位）；Mac 版还没有。
- exe 是 PyInstaller 打的单文件包，每次启动会先把自己解压到临时目录再运行，个别杀毒软件会因此误报。
