# 0.3 更新说明

这一版把「怎么让一群模型猫给你干活」这件事从填表变成了看着办公室一步步发生：打开 exe，首页办公室上会弹出
像素窗口，你一步步把首领和打工猫招进来，它们在办公室里各占一个位置，接活、干活、交回，你不用再对着
一串表单发愁。

0.3 的核心没换名字也没换用法：还是「首领拆活派卡、打工猫接卡干活、首领验收」这一套，核心只监听本机，
数据只写在你自己电脑上。变的是界面、工位、办公室和并发这几块。

## 上岗

- 上岗不再是另一个网页上的 1-2-3 向导了。打开 exe，首页就是办公室，办公室上一步步弹像素窗口带你走：
  先欢迎，再招首领，再招打工猫，每一步都能回头改。
- 招猫是有画面的：快递猫把箱子送进屋、封箱、拆箱，首领戴上王冠才上岗，办公室里的画面跟着你点的下一步走。
- 中途关掉窗口、刷新页面都不怕：上次走到哪一步、填了一半的名字都记着，回来接着走，播过的动画直接摆好，不重播一遍。
- 首领只有一种接入方式：它住在你常用的 AI 客户端的会话里，盒子通过 MCP 跟它说话。上岗时不用选客户端：
  这台电脑上认得出的 Cursor / Claude Code / Codex 一次全写好 MCP 条目，别的客户端用窗口里给的地址。
- 贴进客户端的那段话不再假设 MCP 已经连上（#98）：客户端里 boxbox 没连上（比如 Cursor 里被关掉了），模型会改用 HTTP
  直接找盒子、照样干活，并告诉你怎么把 MCP 打开；盒子没开着，它会请你先打开。上岗窗口和自检也会直接说「Cursor 里 boxbox 是关着的」。
- 打工猫用哪种模型、填什么密钥，上岗时当场测一次：「测试连接」真的用这个密钥问服务商一句（#98 之前填错的密钥也显示连上了），
  通 / 不通、忙、没额度、密钥不对、连不上，分别是不同的说法，不再让你猜是哪一步坏了。
- 上岗进度只记这台机器上，不含密钥；换机器还是从第一步开始。

## 工位

- 工位固定七个：首领占首领的位置，打工猫按 A 到 F 坐，坐满了就是六只打工猫。谁在哪个位置一眼看得见。
- 工位页从表格改成挂绳的工牌：点一张工牌拉出抽屉，里面是这只猫的全部——怎么接活、连没连上、今天干了几张、
  最近十次调度的记录、套餐还剩多少，全在一处，不用来回切页面。
- 想多一只一模一样的打工猫，点工牌上的「复制」：配置和密钥一起复制，名字自动顺延，位置自动往后排；
  它的工作目录会单独给它开一个（不会和你原来那只抢同一个目录），卡上也会提醒可能撞车的文件。
- 删一只正在干活的猫：先中断它手里那张卡、通知首领，页面里再让你确认一次，不会删到一半。
- 服务商和模型可以在工位里选，页面上顺手估一次这次大概要花多少；套餐余额按服务商查一次就记住，不用一只猫查一次。
- 设置页有「重置所有」：点两次确认，清干净重新走一遍上岗，适合想推倒重来的人。

## 办公室

- 办公室重新装修了一遍：大落地窗和外面的城市、光影跟着一天里的时间变；多了一块白板，首领的待办写在上面。
- 工位固定下来了，谁坐哪儿不乱跑；会议室换成了投影幕布加大会议桌，开会的时候幕布会自己亮起来。
- 猫有八种底子，可以戴帽子、围巾、领结、墨镜、耳机；王冠只给首领，首领上岗那一刻戴上。
- 猫不只会干活：会自己去茶水间、会串门、会喝咖啡（杯子空了才去接）、开会时会站起来说话，人多时站着的人不挡幕布。
- 场景来了：分头午睡、加班夜宵、会议室看电影、打游戏比赛、派活站会——该热闹的时候办公室就热闹起来。
- 需要你处理的事集中在一处：办公室顶上的提示条、猫头上冒的叹号、托盘图标和顶栏，用的是同一套分级，
  不会再出现「这边冒红点、那边又闪」的情况。

## 派活和并发

- 同一个模型可以复制出好几只一起干活，各干各的目录，互不干扰。
- 同一个服务商的并发可以设上限：超出上限的卡会排队，看板上写清楚「在等谁、为什么等」。
- 额度按服务商算一份，不是每只猫各扣各的；卡上会带上要动的文件，和别的猫撞了就提醒。
- 首领在客户端的会话里，盒子喊不动它的时候，办公室和托盘会一起提醒你「该叫它了」。

## 稳定性

- 退出（托盘「退出」）、崩溃、被任务管理器直接结束，Pi 打工进程都跟着收工，数据目录不会再被占着删不掉（#76，exe 冒烟里有这一项回归检查）。
- exe 自己带 Node 和 Pi，别的都不用装：拿到 exe 就能用。
- exe 名字带版本号，文件属性里、设置页、托盘提示里都能看到当前版本，升级前后一眼分得清。
- 盒子写进 AI 客户端的 MCP 条目（Cursor / Claude Code / Codex，以及手贴片段的几家）只写一个本机网址，客户端直接连核心，不再拉起 exe 子进程：客户端开着也不会占着 exe，升级、删除 exe 都不受影响。0.2 留下的旧条目自检会标出来，到工位页重新登记一次就换成新写法。
- 对你、对模型说的话统一叫「首领」「打工猫」，不再混用 TeamLeader / Team Member / 打工仔。
- 托盘「退出」时还有卡在跑，弹的确认框是「确定 / 取消」：点取消、按 Esc、点右上角 X 都是不退出。
- exe 从 73 MB 降到 57 MB：去掉了打包时顺带收进来、实际用不到的几个库。
- 自检只检测、不替你动手：每个不过的项都写清楚是什么问题、你该怎么办（要不要重新登记、该结束哪个进程、该用哪个 exe）。
- 顶栏、看板、页面布局做了一轮小修，停靠条、左右对齐、任务卡按日期筛。
- 三个老是看运气的测试改成了确定的结果。

## 许可和隐私

- 设置页最下面多了「数据和隐私」：写清楚哪些数据存在你电脑上、什么时候会联网、发给谁。仓库里的 PRIVACY.md 是同一份。
- 一句话：agent-boxbox 没有账号、没有服务器、不做任何统计；会离开你电脑的，只有打工猫干活时发给你自己选的模型服务商的内容。
- exe 里每个第三方组件的许可全文都带着（设置页「第三方许可全文」），代码本身是 MIT 许可。

## 已知问题

- 从 0.2 升级：客户端里 0.2 写的 MCP 条目还会拉起旧的 boxbox.exe，并一直占着它。自检会标出来；
  到「工位」页把首领和打工猫各重新登记一次，再重启那个客户端，条目就换成只写一个本机网址了。
- 首领走 Pi 接入（上岗第 4 步那个置灰项）挪到 0.5 做（#78），0.3 里首领仍然住在你自己的客户端会话里。
- 路径 B（盒子用脚本驱动 ZCode / Claude Code / Codex 的会话来接活）0.4 之后再做；0.3 的打工猫走路径 A（Pi + API key）或路径 C（客户端定时任务）。工位页「常驻会话」选项先置灰。
- AI 客户端跑在 WSL 里（比如在 WSL 里用 Claude Code / Codex）时连不到盒子：盒子只听 Windows 本机的 127.0.0.1，
  WSL2 默认的网络连不过来。在 Windows 里直接用客户端没有这个问题；WSL 打开「镜像网络」也能连。
- exe 是 PyInstaller 打的单文件包，每次启动会先把自己解压到临时目录再运行，个别杀毒软件会因此误报；这和自检无关。给 exe 做代码签名可以根治，要花钱，0.3 先不做。
- 场景还有几张卡在 0.3 之后接着做（比如一批活全干完的庆祝、出岔子之后的复盘）；已经能用的是上面写的那几个。
