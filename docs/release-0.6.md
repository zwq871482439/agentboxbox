# 0.6 更新说明

0.6 这一版先把「猫猫盒子是干啥的」说清楚：**给你的 AI 编程助手配几个帮手。**
你照常用 Cursor、Claude Code、Codex 这类编程助手，它把活派给盒子里的帮手，每个帮手可以用不同模型平台的 API，做完交回你的会话。

围绕这一句做了四件事：装进去就能用，不用再贴话；界面换成大家都懂的说法；帮手在干什么看得见；在原来的像素办公室上把页面理顺。另外修了一批真用时碰上的坑。

## 装进去就能用

- 上岗第 1 步按你用的编程助手分页签：Cursor 一键安装，Cursor 会问要不要启用，点「启用」；Claude Code、Codex 各给一条终端命令；别的软件给一段连接配置。命令和按钮都由你自己点，盒子不改你软件的设置。
- 装好它会自己连上，等待栏自己变绿，不用在对话里说话。以后在它的任何一个对话里说「把 XX 派给帮手」就行，**不用每开一个新对话就贴一段话**。
- 等太久时，20 秒先查一下 Cursor 里 boxbox 的开关是不是关着，45 秒给一份排查清单。
- 上岗结束时 Cursor 多一个「在 Cursor 里派活」按钮。
- 上岗走完以后也能装：「帮手」页编程助手工牌的「⋯」→「怎么派活」，最上面就是「装进 …」，下面才是复制唤醒话。
- 首页左上角有一张「开始用：三步」小卡（装进编程助手 / 加一个帮手 / 派出第一个任务），三步做完自己收起。右下角是符号图例：! 等你定、? 等编程助手、× 没做成、Zzz 歇着。

## 说大家都懂的话

界面、提示、给编程助手和帮手的说明里，内部说法整版换掉：

| 以前 | 现在 |
|---|---|
| 工位、打工猫 | 帮手 |
| 首领 | 你的编程助手 |
| 卡、派卡 | 任务、派活 |
| 质检 | 自动检查 |
| 验收、打回 | 确认、退回重做 |
| 服务商 | 模型平台 |
| 余量、套餐 | 额度 |

开发者说明式的括号注释也从页面上拿掉了。中英两份一起改。

## 帮手在干什么，看得见

- **一句话状态**：每个帮手一句话，比如「在改 stations.js」「在跑命令：npm test（3 分钟了）」「做完了，等确认」「歇着：额度用完，预计 13:53 回来」「闲着」。帮手页、办公室和编程助手收到的回话里是同一句。
- **点猫看实时动作**：办公室里点一只正在干活的猫，抽屉里列出它最近读了什么、改了什么、跑了什么命令、在想，每 3 秒刷新。只看，不能插话。
- **时间线和交付单**：任务详情先给一条时间线（派活 → 开工 → 退回重做 → 做完了 → 已确认），再给一张交付单，分四栏：改了哪些文件、做了哪些检查、没做完或没把握的、要你确认什么。帮手没写的栏写「没写」，不替它编。编程助手收到的交回就是这张交付单。任务原文和运行记录收进「高级」。
- **效率能按编程助手和批次看**：每个任务分三段时间，等开工、干活、等确认；筛了就列全部，不只列花得最多的 10 个。编程助手确认得比帮手干活慢一倍以上时，它的简报里会说一句。

## 页面理顺（还是原来的像素办公室）

- 顶栏四个页面：**任务、帮手、能力、设置**，都换成米白像素风。
- **帮手页**：每个帮手一张工牌，只留一个「⋯」：改名、换个样子、复制一个、看详情、删除；点工牌就是改配置。改配置只露模型平台、模型、密钥和「测试连接」，接口地址、上下文长度、单价、额度查询收进「高级」，和上岗时加帮手用的是同一张表。
- **能改名**：改的是显示名，手上的任务、额度、密钥、连接地址都不动。
- **任务页**：默认只看帮手、等你处理的、任务三块。用量和效率合成一块「花了多少」，默认收起，点开才算。任务多了打开不再卡。
- **设置页**：默认只留常用几项，其余进「高级」。隐私声明只露一句，点「看全文」再看。临时文件和运行记录合成一行「占用空间」，带一个「清理」。
- **首页办公室**：「动态」「用量」两个按钮挪到最左边，不挡窗户；昼夜只留一个开关，点开横着选。

## 新：「能力」页

帮手干活方式的开关都在这一页。每项写清干什么、多花什么、近 30 天的实测（按开 / 关分组的任务数、用时、轮数）、来源和许可：

- **写代码规则**（默认开）：代码任务带上一份「少写代码、不过度设计」的规则（来自 Ponytail，MIT）。
- **代码搜索工具**（默认关）：给帮手开 Pi 自带的 grep / ls，用盒子自带的 ripgrep。
- **仓库地图**（默认关）：派代码任务时附一页仓库里的文件和函数名，帮手少翻一些文件。
- **任务确认意见**（默认关）：你的编程助手确认任务时说的约束，记进帮手以后的说明。

另有两件盒子一直在做、不给关的：Git 不弹编辑器、命令卡死兜底。

## 帮手更皮实

- **工具跟着盒子走**：自带 rg、fd 和 node，不假设你电脑上装了开发工具。找不到 Git Bash 时自检直说；装好 Git 以后被它卡住的帮手自己恢复，不用重存设置。
- **额度用完歇到重置**：额度用完不再当成「被限流」一轮轮重试。智谱 GLM「每周 / 每月使用上限」这类报错，按报错里写的重置时刻歇着，不是今天的写上日期；同一把密钥的帮手一起歇；查额度看到已经用满，也先歇，派给它的任务排队等它回来。
- **一轮结束收干净**：帮手这一轮起过的程序（测试窗口、后台脚本），交回、失败或撤掉时一起结束，不再一直挂到盒子退出。
- **正在做的任务能叫停**：你的编程助手对正在做的任务用 cancel，盒子停掉帮手和它起的所有程序。说明书里写清了，它不用自己去结束进程。
- **不再弹黑窗**：交回时跑自动检查、派活时问 git，都不再弹终端窗口。
- **撞车提醒按仓库比**：两个任务在同一个 git 仓库的不同工作树里改同一个文件，也会提醒。
- **排队和歇着的几处错**：网回来时一个帮手排着的几个任务不再一起开工；退出时不再顺手开下一个；断网歇着的帮手能回来；探网络时不再占着调度，派活不卡。
- **两处误判**：会话模式上一轮留下的完成标记不再让下一轮自己交回；命令超时不再被当成「密钥错了」把帮手停掉。
- **帮手说明书 v9**：只在工作目录里搜东西，不从盘符根或用户目录开始；不用 `-ExecutionPolicy Bypass`、`-EncodedCommand` 起 PowerShell；不占你的屏幕（不开全屏窗口、不抢焦点、不动真的鼠标键盘和剪贴板），要这样才能做的检查标「没跑」。

## 更快、更稳、更安全

- **任务多了不卡**：顶栏和办公室每 5 秒数一遍的数只走索引；「花了多少」从几秒降到零点几秒，而且点开才算；待办不再每次起 PowerShell，模型平台清单不再每次重读 830 KB。
- **安全**：本机接口挡掉别的网站发来的请求（查 Host 和跨站）；额度报错里的文字转义后再显示；自动检查命令里的工作目录不让任务自己填。
- **不误伤你的程序**：重启后不再按旧进程号接管任务，Windows 上一律记成「中断」。
- **配置不写坏**：读不懂的配置先另存一份；写盘写稳再换；设置项都校验，存设置加锁；改过显示名的帮手再存配置名字不丢，复制帮手不连名字一起复制。
- **Windows 上几处**：中文路径下开机自启起得来；临时目录里的只读文件删得掉；重置以后不留旧临时文件和托盘通知。
- **页面上几处**：存密钥失败不再显示「已保存」；核心重启后办公室的猫不再全体退场；「打开它在做的任务」打得开；确认结果不再一闪就没。
- **托盘自己写**：不再用 pystray，exe 里没有 LGPL 组件了。

## 升级

- 最简单：从托盘退出 0.5，把新 exe 放进原来那个文件夹，双击。`data\` 沿用，帮手、设置和任务都还在。
- 要放新文件夹：先退出旧版，再到新版「设置」→「数据和隐私」→「从旧版导入」，填旧版文件夹。不要在旧版还开着时拷 `data\`。
- 0.5 里是贴一段话连上的编程助手照样能用。想以后新对话不用再贴：到「帮手」页编程助手工牌的「⋯」→「怎么派活」，点「一键装进 Cursor」；用 Claude Code、Codex 的复制那条命令到终端里跑一次。
- 帮手和编程助手的说明书第一次用到时自动换成新版，你改过的旧版留一份 `.bak`。

## 已知问题

- 交付单「改了哪些文件」只列帮手用改文件工具改的；帮手用命令行写出来的文件不列。
- 编程助手中途给帮手的留言，要等帮手干完这一轮才送到。急事先叫停再重派。
- 盒子还拦不住帮手跑大范围的搜索或占屏幕的命令，目前只写在说明书里；单条命令跑满 30 分钟才会被停下。
- 「能力」页的开关是全局的，开 / 关两组的实测要你自己开一阵、关一阵才有数；让一半任务开、一半关的对比模式在后面的版本里做。
- 同一个 AI 软件窗口里的两个对话可能共用一条连接，盒子认不出是两个对话。各加一个编程助手就没有这个问题。
- AI 软件跑在 WSL 里时连不到盒子：盒子只听 Windows 本机的 127.0.0.1。
- 目前只有 Windows 版（Windows 10 / 11，64 位）。
- exe 是 PyInstaller 打的单文件包，每次启动会先解压到临时目录再运行，个别杀毒软件会因此误报。

## In English (short)

0.6 makes the point of agentboxbox clear: **a few helpers for your AI coding assistant.** You keep using Cursor,
Claude Code or Codex; it hands work to helpers in the box, each on its own model platform's API, and the results come
back to your chat. Install it once (one click for Cursor, one command for Claude Code and Codex) and it connects on its
own: no more pasting a text into every new chat. You can also install it later from the Helpers page (“…” → “How to give
work”). The pages now use plain words (helper, task, auto check, confirm) instead of internal terms. You can see what each
helper is doing: one status line shared by every page and by your assistant, a live view of a working helper's actions,
and a timeline plus a hand-off sheet for every task. The pages are tidied on top of the same pixel office, and a new
Capabilities page holds the switches for how helpers work, with measured results and licenses. Helpers rest until the
quota resets instead of retrying, everything a run started is stopped when it ends, no console windows pop up, and a long
task list no longer slows the pages. To upgrade, quit 0.5 and put the new exe in the same folder.
