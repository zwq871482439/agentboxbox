The **full licence text** of every component is in [THIRD_PARTY_LICENSES.txt](THIRD_PARTY_LICENSES.txt) (generated by `packaging/licenses.py`; the build checks that what goes into the exe matches that list). The settings page of the exe opens these files as well.

## Art and assets of this repository

- **Pixel cats, the office, the props, the onboarding animations** (`office/`, `assets/chibicat/`, `assets/design/`): original to this repository and drawn on the canvas by code (`office/office.html`, `office/build/cats.js`), distributed under the MIT licence together with the code. The morning, day and evening backgrounds of the office are drawn by the canvas code, not external images.
- **Application icon** (`assets/icon/`): generated with Grok (xAI), picked by the maintainer and cut with `make_icons.py`; used under the xAI terms of service. We offer it under the MIT licence to the extent we hold rights in it.
- **Promo clips** (`assets/promo/`): the frames are drawn by a script, the music is synthesised with numpy by `make_music.py`. The subtitles use Noto Sans CJK SC (SIL Open Font License 1.1); no font file is kept in the repository.
- **Screenshots** (`office/screenshots/`, `office/mockups/`): all of them are this application's own interface.

## Third-party components inside the exe

The exe is a single-file package built with PyInstaller; it carries the following (the versions are listed in THIRD_PARTY_LICENSES.txt):

| Component | Licence | What it is used for |
|---|---|---|
| Python runtime and standard library | PSF-2.0 | runs agentboxbox |
| pywebview, pythonnet, clr_loader, bottle, proxy_tools, cffi, pycparser, typing_extensions | BSD-3-Clause / MIT / PSF-2.0 | the embedded window |
| Microsoft WebView2 SDK DLLs (shipped with pywebview) | BSD-3-Clause (Microsoft) | the embedded window; the WebView2 runtime itself is a Windows component and is not in the exe |
| PyInstaller bootloader | GPL-2.0-or-later with the packaging exception | the shell of the exe. That exception explicitly allows distributing programs built with it under any licence |
| Node.js | MIT (including the licences of its own components) | runs Pi |
| Pi (`@earendil-works/pi-coding-agent`) and the npm dependencies it bundles | MIT, the dependencies include Apache-2.0, BSD-3-Clause, ISC, BlueOak-1.0.0, 0BSD, Unlicense | the command line agent the worker cats use |
| ripgrep (rg.exe) | Unlicense OR MIT | the bundled search tool the worker cats and Pi use to search file contents |
| fd (fd.exe) | MIT OR Apache-2.0 | the bundled search tool for finding files by name |

All of these licences allow redistribution as long as the copyright notice and the full licence text come with it — that is what THIRD_PARTY_LICENSES.txt is for, and the exe carries it too. We did not change the source of any of these components. The tray icon and its menu are our own code (`boxbox/tray_win.py`, plain ctypes calls into Windows); there is no LGPL component in the exe.

## Things we do not bundle and you install yourself

agentboxbox calls or reads the following, but does not carry them: AI clients (Cursor, Claude Code, Codex, Kimi Code, MiniMax Code, Grok Bot, WorkBuddy, ZCode), Git (it only runs `git` commands to read commit records) and the API of the model provider you picked. Their licences and terms are between you and them.
