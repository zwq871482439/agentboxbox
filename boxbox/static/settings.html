盒子参数

语言 界面、上岗话和办公室用哪种语言。选了就一直按这个来。
多久提醒你去叫首领 首领手上有待办、却这么多分钟没来看，别的猫会围过去冒问号，办公室顶上也会提示你去叫它。 分钟
启动等待 盒子自动启动一个工位后，最多等几秒启动器回一句「已启动」；超时了就当这张卡没送出去，不会自动重试，换不换工位由你定。 秒
检查间隔 盒子多久查一遍任务执行情况：工位进程还在不在、交没交付、要不要提醒你。不查 API key 余额。 秒
完成后首领冒气泡叫你看庆祝 / 复盘 卡验收通过、同一目标的一批全部完成、或出了事故时，首领在办公室冒气泡邀请你看庆祝 / 开复盘，点了才演。不勾就只有办公室自己演，首领不邀请。
首领的验收反馈写进打工猫的说明 首领验收时多给的一句约束（哪里偏了、下次怎么做），之后派给这只猫的每张卡都会带上。默认关。
反馈最多多少字 每只猫那段反馈的上限（不少于 120）。超了先挤掉最旧的，免得说明越写越长、每张卡都要多付模型的钱。 字
卡交回、出问题时在桌面弹通知 猫把卡交回了、没跑成、没开工或等首领拿主意时，盒子在桌面右下角弹一条系统通知，提醒你去会话里跟首领说一声。
办公室昼夜 「自动」档按电脑时间换房间配色，清晨和傍晚是两段渐变。办公室里霓虹招牌下面的开关可以固定成某一段。
服务商清单 登记 Pi 工位时从这里选服务商和模型，再按公开单价估算花费。清单来自 models.dev（MIT）。「更新」要从网上下载最新的一份。 正在读…

临时文件 过程垃圾（存请求正文的 JSON、试跑脚本、中间文件）都在程序目录的 tmp\ 里，每张卡一个子目录。 默认留 1 天（设置项 tmp_keep_days），没有卡在跑的时候整个 tmp\ 随时能删，data\ 不动。 –
