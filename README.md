# 猫猫盒子（agentboxbox）

[English version](README.en.md)

**装在你自己电脑上的一间像素猫猫办公室：一位首领把活拆成任务卡派给几只打工猫，干完先过机器质检，再由首领验收。**

给已经在用一个贵 agent（Cursor / Claude Code / Codex）当首领、想让几个便宜些的模型当打工猫一起给一个项目干活的人。全部跑在你自己的电脑上，没有账号和服务器；除了打工猫干活时调用你自己选的模型服务商，不往外发任何东西（详见 [PRIVACY.md](PRIVACY.md)）。猫猫盒子不改你 AI 软件里的任何设置。

现在的状态：0.5.0 已正式发布。exe 只有 Windows 版；界面、上岗话和办公室都有中英双语，第一次打开跟系统语言走，欢迎窗口和设置页里能随时切。打工猫只有两种接活方式：用 API key 自动跑，或者会话模式（你的 AI 软件定时来领卡）。

## 它做什么

- 首领把活拆成**自包含的任务卡**，派给各个工位；
- 工位干完交付，先过**质检**（机器检查，免费），再由**派活人验收**；
- 等待全部由盒子自己负责（送达回执、心跳、看门狗），模型从不自己轮询；
- 首页一页看全：办公室里谁在干活、谁闲；看板上看每张卡、等了多久、花了多少。

打工猫只有两种接活方式（一个工位选一种）：

| 接活方式 | 怎么接活 | 谁适用 |
|---|---|---|
| 用 API key 自动跑 | 盒子自己用 Pi 一张卡起一个进程（填服务商、模型、API key），做完退出 | 有按量付费 API key |
| 会话模式 | 你的 AI 软件每隔几分钟开一个新对话来领卡：盒子把卡写在一个文件里，猫读完写回报；不用 API key，不分是哪个软件 | 已经在 AI 软件里干活的 |

首领只有一种接入方式：住在你常用的 AI 软件的会话里，盒子通过那个软件的工具接口跟它说话（上岗第 3 步贴的那段话里带着地址）。盒子自己不养首领，也没有「和首领说话」这个入口——首领始终在你那边的软件里。可以有好几个首领：两个项目各开一个对话当首领时，在工位页点「再加一个首领」，把新地址给其中一个对话；每个首领只看、只验自己派的卡，猫大家共用。两个对话连着同一个首领时，盒子会在回话和工位页里提醒你。

## 怎么安装

- **系统要求**：Windows 10 / 11，64 位。用 exe 的话不用装 Python、Node——都打包在 exe 里了。
- **用 exe**：在 https://github.com/zwq871482439/agentboxbox/releases 下载 `agentboxbox_<版本号>.exe`（发版仓打个标签，流水线就自动打 exe、算校验和、把这一版的说明一起发出来）。先新建一个单独的文件夹，把 exe 放进去再双击。exe 旁边会生成两个文件夹：`data\` 放配置和记录（工位、密钥、任务、日志），**不能随便删**；`tmp\` 放干活时的过程垃圾，卡完成或撤掉就自动清掉，**没有卡在跑时随时可以整个删掉**（设置页也有一键清理）。`data\` 里结束的卡的运行记录过几天自动压缩、再过一阵删掉，天数在设置页「高级」里改。别把 exe 放到桌面上一堆文件里或下载目录里。
- **第一次打开**：首页办公室上会弹窗口带着走上岗，托盘右下角出现猫图标。点窗口右上角 × 只是缩到托盘；要退出就在托盘猫图标上右键选「退出」。想开机自动打开，在托盘菜单里勾「开机启动」。
- **卸载**：托盘退出后把整个文件夹删掉即可。开过「开机启动」的话，先在托盘菜单取消勾选再删（不然 Windows「启动」文件夹里会留一个快捷方式）。Windows 会在注册表里留一条托盘图标的显示设置，不影响使用。猫猫盒子不往别的软件里写配置，删文件夹就删干净了。
- **从源码运行（给开发者）**：需要 Python 3.11+，在仓库根目录运行 `python -m boxbox serve`，再用浏览器打开 `http://127.0.0.1:8878`。

### 怎么升级

- **最简单**：从托盘退出旧版，把新 exe 放进旧版那个文件夹，双击。`data\` 沿用，猫、设置和卡都还在。用完可以删掉旧 exe。
- **要放进一个新文件夹**：先从托盘退出旧版，再打开新版，到设置页「数据和隐私」里「从旧版导入」，填旧版文件夹（或它里面的 `data\`）。不要在旧版还开着的时候把 `data\` 拷过去：拷完之后，旧版里新派的卡、交回和验收都不会带过来。

## 上岗怎么走

第一次打开，首页办公室上会一步步弹像素窗口，十来分钟走完（中途关掉、刷新都行，走到哪一步都记着，回来接着走）：

1. **欢迎**：说一句这是什么。
2. **招首领**：起个名字、挑个样子。
3. **复制一段话，贴进你常用的 AI 软件（Cursor、Claude Code、Codex 等都行）的新对话**：那段话是写给 AI 看的，整段复制发送就行，里面的 AI 就成了首领，先调 get_briefing 拿上岗说明，再按话里的地址直接连上猫猫盒子开始干活。它连上后可能会问你「要不要把盒子加进我的工具列表」——由你决定；**猫猫盒子不会改你电脑上任何软件的设置**。
4. **招打工猫**：起名字、挑样子，再选一种接活方式（「用 API key 自动跑」填服务商、模型、密钥，当场点「测试连接」真的问服务商一句；「会话模式」不用填 key）。测不通也不耽误招：连不上的话这只猫先招进来，派给它的卡会排队，接口通了自动开工。
5. **派第一张卡**：上岗结束窗口给一句能直接复制的示范（「帮我派一张卡：……」），回到首领那个对话发出去；也可以直接对首领说想干什么，它会写成卡派出去。

界面、上岗话和办公室画面的文字都跟着界面语言走。语言是第一次打开时按系统语言定的，欢迎窗口里有个「中文 / English」小开关，当场就能换；以后在设置页的「盒子参数」里也能改。

以后每次在 AI 软件里新开一个对话，都要把那段话再贴一遍（工位页工牌上有「叫醒首领」，复制的是同一段）。

## 平时怎么用

**首页（`/`）就是办公室**：顶栏右边是「工作中 / 成功率 / 自检」，下面整屏是办公室画面。

- 画面里挂着**昼夜开关**（自动 / 清晨 / 白天 / 傍晚 / 夜晚，自动档跟本机时间走，时间点在设置页改）和**「动态」「用量」两个按钮**（点开是小浮窗，有新动静带红点）。
- 会议室投影机旁有台**聚会街机**：点它弹「聚会」菜单，放电影、来一局、或让猫们回去干活。猫也会自己组织：分头午睡、加班夜宵、开会站会、干完一批庆祝。
- **点一只猫看详情**：状态、在干哪张卡、后面排了几张、剩余额度、最近活动。
- 顶上要你处理的事会有提示条，托盘图标和顶栏用的是同一套分级，不会这边冒红点那边又闪。

**桌面通知**：首领在你自己那边的软件里，那边的会话闲着时盒子叫不醒它。所以卡交回、没跑成、没开工、卡住或等首领拿主意时，盒子在桌面右下角弹一条系统通知，提醒你去会话里跟首领说一声。不想收就在设置页把「卡交回、出问题时在桌面弹通知」关掉。

**猫的几种状态**：

| 状态 | 什么意思 |
|---|---|
| 在跑 | 正在干活（后面还排着卡会写「在跑 · 后面排 N 张」）|
| 闲 | 没活，可以派 |
| 歇着 | 暂时干不了：额度用完 / 被限流 / 接口连不上 / 服务商出错。带原因和预计回来的时间，到点自动回来接着干 |
| 已停用 | 你在设置里手动关掉了，不会自动恢复 |

**卡排队写的是什么意思**：排在队里的卡写清楚在等谁——等某只猫干完手上这张、等它歇完回来、还是等接口连通。一只猫同一时间只干一张卡；同一个服务商想同时多跑几张，就多招几只猫（或者点工牌上的「复制」）。开工前被拦下的卡显示「没开工」，不算失败；首领能重派或撤掉。

**接口报错断在半路的卡**：打工猫干到一半遇上模型接口出错（连不上、限流、服务端出错），这张卡不记失败，也不丢：猫出去歇着，卡回队列等它，猫回来后接着上次的对话继续干。同一张卡这样自动续跑最多三次，还不行才记成「中断」，交给你和首领定。

**中断的卡**（上次退出或崩溃时没干完的）下次打开首页会问你：接着上次的对话继续干、交给首领决定、还是先不管。

**工位页（`/stations`）**：挂绳工牌，首领加打工猫 A–F 共 7 个位置。点工牌看详情（怎么接活、连没连上、今天的活、最近调度、套餐余量）；工牌上能「复制」（配置和密钥一起复制，名字自动顺延，工作目录单独开一个）和「删除」（正在干活的会先问一次，确认就中断那张卡）；「修改配置」换猫样子、名字或接活方式（首领只能换样子）。

**查余量（套餐还剩多少）**：现在认得三家编程套餐——Kimi Code 会员、智谱 GLM Coding Plan、MiniMax Token Plan（工位里填了这几家的接口地址就自动选好查法）；别家在工位设置里选「自定义」，填查询地址和返回里已用百分比的路径。结果在工位详情和看板的「用量」里。

**看板（`/board`）**：每张卡从派出到在跑到验收的全过程，工位一行（状态词、当前卡、分钟），卡的详情里有实测用量。

**设置（`/settings`）**：盒子参数（语言、提醒节奏、桌面通知、服务商清单、办公室昼夜）、数据和隐私、临时文件清理、页底「重置所有」（两次确认，清干净重走上岗）。

出问题先看顶栏「自检」（点开是逐项检查结果，每项写了怎么办），或自检页（`/doctor`）的「复制诊断信息」（已把路径和密钥打码，贴 issue 前自己再过一眼）。0.4 具体变了什么，看 [`docs/release-0.4.md`](docs/release-0.4.md)；从 0.2 升上来的话先看 [`docs/release-0.3.md`](docs/release-0.3.md) 末尾的「已知问题」。

## 给开发者

命令、概念、接口和目录结构。日常使用不用看这一节。

### 命令速查

每个命令都能加 `--lang zh|en` 换输出语言（不写就跟盒子当前的语言走）。

| 命令 | 作用 |
|---|---|
| `python -m boxbox serve [--port 8878]` | 起核心（HTTP + 看门狗 + SQLite），只监听 127.0.0.1 |
| `python -m boxbox tray [--show] [--port 8878]` | 托盘壳：托盘图标 + 内嵌窗口（需 `pip install pystray pywebview`）；双击 exe 等价于 `tray --show` |
| `python -m boxbox mcp --station <工位> --core <URL>` | MCP stdio 门面：只留给不认 `url` 的客户端手动配置用。盒子给的所有条目都只写 `http://127.0.0.1:8878/mcp?station=<工位>`，客户端直接连核心，不起子进程 |
| `python -m boxbox doctor [--json] [--no-core]` | 自检：核心 / 数据目录 / 首领 / Pi / 模板 |
| `python -m boxbox board` | 看板：每工位一行 |
| `python -m boxbox todo` | 首领待办：待验收、卡住、闲着的工位 |
| `python -m boxbox task <id>` | 看一张任务卡的全部 |
| `python -m boxbox wait [--timeout 600] [--station 猫猫首领] [--port 8878]` | 等猫交回卡：有新动静打印一行行（退出码 0），等不到 2，核心没开 3 |
| `python -m boxbox report --task <id> --status done --summary "..."` | 打工猫回报（heartbeat / done / blocked / issue）|
| `python -m boxbox assign --station <工位> --card card.json` | 派一张卡（正常由首领调 assign）|
| `python -m boxbox review --task <id> --verdict accept --note "..."` | 验收：accept 或 return（打回重派）|

同端口已有核心在跑时，`tray`（含双击 exe）会直接接上它，不另起核心、也不用自己的 `data/`。

### 概念

| 概念 | 含义 |
|---|---|
| 工位 | 一个角色的座位：名字 + 接活方式（用 API key 自动跑 / 会话模式）|
| 首领 | 主模型工位：写卡、派活（assign）、验收（review）。只有一个；再登记一个新首领就是把旧的换掉（英文文档里叫 leader）|
| 打工猫 | 辅助模型工位：接卡、干活、回报（report）。没有派活权限（英文文档里叫 worker cat）|
| 任务卡 | 派活的唯一单位，**自包含**（新会话没有旧上下文）：`goal` / `inputs` / `expected_output{kind,path}` / `acceptance{review}` 四个必填，缺了 assign 直接拒收 |
| 质检 | 交付后先跑的机器检查（exists / headings / command / commits / json / size），免费；任一不过直接打回，不经过首领。卡上的字段仍叫 `acceptance.gates` |
| 验收 | 谁派活谁验收：质检过后由派活人评审（也可交给用户定、或质检过即完成）|
| 接活方式 | 打工猫怎么接活：`once`（用 API key 自动跑：盒子用 Pi 一张卡起一个进程）/ `scheduled`（会话模式：读交换文件领卡）；首领是 `manual`（你在 AI 软件里开对话）|
| 语言 | 界面语言记在设置里的 `ui_lang`（zh / en），没设过时按系统语言定；页面词表在 `boxbox/static/i18n-*.js`，后端词表在 `boxbox/i18n_data/` |

### 页面与接口

页面（都在 `http://127.0.0.1:8878`）：

- `/` 首页（办公室画面）：顶栏 + 整屏办公室；昼夜开关、动态 / 用量按钮、聚会街机都在画布里；点猫看详情；**上岗就在这里一步步弹窗口**
- `/board` 看板：工位（带模型、余量、几点回来）、待办、任务卡、用量、效率（每张卡 / 每只猫花了多少时间和用量）
- `/stations` 工位：挂绳工牌（首领 + A–F），点工牌看详情抽屉，工牌上能复制、删除、修改配置；「再加一个首领」
- `/settings` 设置：盒子参数、数据和隐私（临时文件、数据目录占多少、从旧版导入）、高级（卡住提醒、运行记录怎么记和留多久）、重置所有
- `/doctor` 自检：逐项检查结果、怎么办、复制诊断信息
- `/office` 办公室画面单独页（首页嵌的就是它）
- `/onboard` 旧地址，打开只会跳回首页

接口（GET 只读；写操作只接受本机同源请求；`/mcp?station=<工位>` 和 `/rpc/<工具>` 给模型走 JSON-RPC）：

- `/api/meta` 顶栏数据：在跑数、成功率、提醒
- `/api/stations` 每个工位：状态词、当前卡、分钟、位置
- `/api/stations/detail` 工位详情（配置不含密钥 + 连接 + 调度记录 + 余量）
- `/api/tasks` 任务板（可加 `?state=` 过滤），每张带排队原因
- `/api/tasks/<id>` 一张卡的全部：卡、运行记录、回报原文、实测用量
- `/api/todo` 待办：待验收、卡住、打回待定、中断、没开工、失败，闲着的工位
- `/api/interrupted` 上次退出 / 崩溃时中断的卡（POST `/resume` 接着做、`/dismiss` 先不管）
- `/api/timeline` 最近的运行和事件流水
- `/api/tokens` 实测用量（只记能精确测量的；没有接口的工位显示「不计」）
- `/api/doctor` 自检结果（JSON；`?text=1` 给可复制的诊断文本）
- `/api/settings` 常用参数（含 `ui_lang` 界面语言）；`/api/providers` 服务商清单（`/refresh` 更新）
- `/api/stations_def` 工位登记（`stations.json` 的内容）
- `/api/onboard/state` `/api/onboard/progress` 上岗进度（步骤、播过的动画、填了一半的表单；progress 的 POST 合并更新）
- `/api/stations/copy`（POST）复制一只打工猫：配置和密钥一起复制，名字自动顺延，占下一个空位
- `/api/stations/delete`（POST）删工位；正在干活的不带 `confirm` 会先回 busy，带上才中断那张卡
- `/api/reset`（POST）重置所有：清工位、设置、密钥、任务记录和日志，保留 `data/work`；有卡在跑要先 `force`
- `/api/shutdown`（POST）核心自己收工：和托盘「退出」同一条路（结束在跑的打工进程、关数据库）
- `/api/tmp` 临时文件占多大（`/api/tmp/clean` POST 清理）
- `/api/data` 数据目录占多大、其中运行记录多少（`/api/data/clean` POST 现在压缩结束的卡的记录）
- `/api/efficiency` 效率：近几天每张卡 / 每只猫的用时、轮数、用量（`?days=7`）
- `/api/import_old`（POST）从旧版导入：旧版先退出，这台盒子还没有卡时才能导
- `/api/connectors` 支持的客户端清单；`/api/connectors/snippet` 给某工位生成可手贴的连接片段
- `/api/summon/<工位>` 「叫醒首领」：按接活方式给那段话、贴到哪、分几步
- `/api/office` 办公室画面的数据
- `/api/health` 存活检查

### 目录结构

```
boxbox/      核心（app / store / dispatcher / watchdog / tokens / gates / office_feed / scenes）
             facades/（mcp_stdio · cli · http，都是薄壳，不持状态）
             runners/（base · pi：用 API key 自动跑 · scheduled：会话模式读交换文件）
             i18n_data/（后端词表，zh / en 两份）
             static/（首页 · 看板 · 工位 · 上岗 · 设置 · 自检页 + i18n-*.js 页面词表）
             templates/（首领 / 打工猫的说明模板，每份都有中文和英文两版）
packaging/   打包脚本（build_exe.ps1 → 单文件 agentboxbox_<版本号>.exe，Node 和 Pi 一起打进去）
assets/      图标和像素立绘（原创）
office/      办公室画面（/office 与首页内嵌）
static/tabler 离线样式（首页外壳用的 tabler.min.css）
docs/        每个版本的更新说明（release-*.md）
data/        运行时数据：boxbox.db、stations.json、secrets.json、tasks/、logs/（gitignored，不入库；exe 模式下在 exe 旁边）
tmp/         临时文件：每张卡一个子目录，自动清理（gitignored；exe 模式下在 exe 旁边）
```

## 已知限制

- 会话模式：每次来领卡都没有上下文；你那边的定时任务没触发时，盒子只能提醒，拉不起来。
- Cursor IDE 当首领：外部叫不醒，只能托盘红点 + 「叫醒首领」提示人；IDE 会话与 CLI 会话不互通。
- 用量只有实测：会话模式的猫和 Cursor IDE 首领的消耗不计；「省了多少」暂不展示。

另外几条现状：

- exe 是 PyInstaller 打的单文件包，每次启动会先解压到临时目录再运行，个别杀毒软件会误报。
