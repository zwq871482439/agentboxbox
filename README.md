# 猫猫盒子（agentboxbox）

[English version](README.en.md)

**给你的 AI 编程助手配几个帮手。** 你正在用的 AI 编程助手拆任务、检查结果；猫猫盒子把活分给你配好接口的其他模型，同时做、做完交回到你的会话。

给已经在用 Cursor、Claude Code、Codex 这类编程助手的：盒子全部跑在你自己的电脑上，没有账号和服务器；除了帮手干活时调用你自己选的模型平台，不往外发任何东西（详见 [PRIVACY.md](PRIVACY.md)）。猫猫盒子不改你 AI 软件里的任何设置。

现在的状态：0.6.0 已正式发布。exe 只有 Windows 版；界面、给编程助手和帮手的说明、办公室都有中英双语，第一次打开跟系统语言走，欢迎窗口和设置页里能随时切。

## 它做什么

- 你的编程助手照常和你聊、拆活；要派出去的，它写成一个**自成一体的任务**（目标、给哪些文件、交什么、怎样算做完）派给帮手；
- 帮手做完交回，先过**自动检查**（机器检查，不花用量），再由你的编程助手**确认**，不行就**退回重做**；
- 交回时附一张**交付单**：改了哪些文件、做了哪些检查、没做完或没把握的、要你确认什么；
- 等待全部由盒子自己负责（送达回执、心跳、看门狗），模型不用自己轮询；
- 首页是一间像素办公室：谁在干活、谁闲着、谁在歇着，每个帮手一句话说清在干什么。

帮手有两种干活方式（一个帮手选一种）：

| 干活方式 | 怎么干 | 适合 |
|---|---|---|
| 用 API key 自动跑 | 盒子自己用 Pi 为每个任务起一个进程（选模型平台、模型，填 API key），做完退出 | 有模型平台 API key 的，按量付费或编程套餐都行 |
| 会话模式 | 你的 AI 软件每隔几分钟开一个新对话来领任务：盒子把任务写在一个文件里，它读完写回报；不用 API key，不分是哪个软件 | 已经在 AI 软件里干活的 |

你的编程助手就是你平时用的 Cursor、Claude Code、Codex（或别的认 MCP 的 AI 软件）。把猫猫盒子装进去一次，它就能调盒子的工具：派活、等交回、确认。盒子自己不养编程助手，也没有「在盒子里跟它说话」的入口，它始终在你那边的软件里。可以有好几个编程助手：两个项目各开一个对话时，在帮手页右上「⋯」点「再加一个编程助手」；每个编程助手只看、只确认自己派的任务，帮手大家共用。

## 怎么安装

- **系统要求**：Windows 10 / 11，64 位。用 exe 的话不用装 Python、Node——都打包在 exe 里了，搜索工具也自带。帮手跑命令要用 Git Bash（装 Git 时自带）；没装的话自检会直说。
- **用 exe**：在 https://github.com/zwq871482439/agentboxbox/releases 下载 `agentboxbox_<版本号>.exe`（每个版本都附校验和和这一版的说明）。先新建一个单独的文件夹，把 exe 放进去再双击。exe 旁边会生成两个文件夹：`data\` 放配置和记录（帮手、密钥、任务、日志），**不能随便删**；`tmp\` 放干活时的过程垃圾，任务完成或撤掉就自动清掉，**没有任务在跑时随时可以整个删掉**（设置页「占用空间」也能一键清理）。`data\` 里结束的任务的运行记录过几天自动压缩、再过一阵删掉，天数在设置页「高级」里改。别把 exe 放到桌面上一堆文件里或下载目录里。
- **第一次打开**：首页办公室上会弹窗口带着走上岗，托盘右下角出现猫图标。点窗口右上角 × 只是缩到托盘；要退出就在托盘猫图标上右键选「退出」。想开机自动打开，在托盘菜单里勾「开机启动」。
- **卸载**：托盘退出后把整个文件夹删掉即可。开过「开机启动」的话，先在托盘菜单取消勾选再删（不然 Windows「启动」文件夹里会留一个快捷方式）。装进编程助手的那条连接在它自己的 MCP 设置里，要删就在那边删。Windows 会在注册表里留一条托盘图标的显示设置，不影响使用。
- **从源码运行（给开发者）**：需要 Python 3.11+，在仓库根目录运行 `python -m boxbox serve`，再用浏览器打开 `http://127.0.0.1:8878`。

### 怎么升级

- **最简单**：从托盘退出旧版，把新 exe 放进旧版那个文件夹，双击。`data\` 沿用，帮手、设置和任务都还在。用完可以删掉旧 exe。
- **要放进一个新文件夹**：先从托盘退出旧版，再打开新版，到「设置」→「数据和隐私」里「从旧版导入」，填旧版文件夹（或它里面的 `data\`）。不要在旧版还开着的时候把 `data\` 拷过去：拷完之后，旧版里新派的任务、交回和确认都不会带过来。
- **从 0.5 升上来、当初是贴一段话连上的**：照样能用。想以后新对话不用再贴，到「帮手」页编程助手工牌的「⋯」→「怎么派活」，点「一键装进 Cursor」，或者把 Claude Code / Codex 那条命令复制到终端里跑一次。

## 上岗怎么走

第一次打开，首页办公室上会一步步弹像素窗口，几分钟走完（中途关掉、刷新都行，走到哪一步都记着，回来接着走）：

1. **欢迎**：一句话说这是什么，一条流程条（你的编程助手 → 派活 → 帮手们 → 做完交回 → 你的会话）。
2. **装进你的编程助手**：按你用的那个选页签。Cursor 点「一键装进 Cursor」，Cursor 会问要不要启用 boxbox，点「启用」；Claude Code、Codex 各给一条命令，复制到终端里跑一次；别的软件给一段连接配置。装好它会自己连上，这一步自己变绿，**不用在对话里说话**。命令和按钮都由你自己点，**猫猫盒子不改你电脑上任何软件的设置**。这一步顺便给它挑个样子。
3. **加一个帮手**：起名字、挑样子，再选一种干活方式。「用 API key 自动跑」选模型平台和模型、填密钥，当场点「测试连接」真的问一句；「会话模式」不用填 key。测不通也不耽误：先加进来，派给它的任务排队，接口通了自动开工。
4. **派第一个任务**：回到你的编程助手，在任何一个对话里说「把 XX 派给帮手」；用 Cursor 的还有一个「在 Cursor 里派活」按钮。

界面、上岗话和办公室画面的文字都跟着界面语言走。语言是第一次打开时按系统语言定的，欢迎窗口里有个「中文 / English」小开关，当场就能换；以后在设置页也能改。

## 平时怎么用

顶栏四个页面：**任务、帮手、能力、设置**；右边是「工作中 / 成功率 / 自检」。

**首页（`/`）是办公室**：

- 左上角刚上岗时有一张「开始用：三步」小卡，三步做完自己收起；右下角是符号图例：! 等你定、? 等编程助手、× 没做成、Zzz 歇着。
- 画面左边是「动态」「用量」两个按钮（点开是小浮窗，有新动静带红点），旁边一个昼夜开关（自动 / 清晨 / 白天 / 傍晚 / 夜晚，自动档跟本机时间走，时间点在设置页改）。
- 会议室投影机旁有台聚会街机：放电影、来一局、或让猫们回去干活。猫也会自己组织：分头午睡、加班夜宵、开会站会、干完一批庆祝。
- **点一只猫看详情**：状态、在做哪个任务、后面排了几个、剩余额度、最近活动；正在干活的猫还能看它最近的动作（读了什么、改了什么、跑了什么命令），每 3 秒刷新，只看不能插话。

**任务页（`/board`）**：默认三块——帮手（每个一行，一句话状态）、等你处理的、任务列表。点任务看时间线和交付单，原文和运行记录在「高级」里。用量和效率合成一块「花了多少」，默认收起，点开才算；效率能按编程助手和批次看每个任务的等开工 / 干活 / 等确认三段时间。

**帮手页（`/stations`）**：挂绳工牌，编程助手加帮手 A–F 共 7 个位置。点工牌就是改配置（只露模型平台、模型、密钥、测试连接，其余在「高级」）；工牌上的「⋯」里有改名、换个样子、复制一个、看详情、删除；编程助手的「⋯」里有「怎么派活」（装进编程助手，或者复制一段唤醒话）。改名改的是显示名，任务、额度、密钥和连接都不动。

**能力页（`/capabilities`）**：帮手干活方式的开关，每项写清干什么、多花什么、近 30 天实测、来源和许可：写代码规则（默认开）、代码搜索工具、仓库地图、任务确认意见（这三项默认关）。

**设置页（`/settings`）**：常用几项（语言、桌面通知、办公室昼夜），「高级」里是提醒节奏、卡住提醒、运行记录怎么记和留多久；「占用空间」一行加清理；隐私声明和许可点开看全文；页底「重置所有」（两次确认，清干净重走上岗）。

**帮手的几种状态**：

| 状态 | 什么意思 |
|---|---|
| 在跑 | 正在干活（后面还排着任务会写「在跑 · 后面排 N 个任务」），一句话状态写着在读、在改还是在跑什么命令 |
| 闲 | 没活，可以派 |
| 歇着 | 暂时干不了：额度用完 / 被限流 / 连不上 / 服务端出错。带原因和预计回来的时间（额度用完就歇到报错里写的重置时刻，同一把密钥的帮手一起歇），到点自动回来接着干 |
| 配置有问题 | 模型 id 或密钥不对，不接活；到帮手页改好就恢复 |
| 已停用 | 你在设置里手动关掉了，不会自动恢复 |

**排队写的是什么意思**：排着的任务写清楚在等什么——等某个帮手干完手上这个、等它歇完回来、还是等接口连通。一个帮手同一时间只做一个任务；同一个模型平台想同时多跑几个，就多加几个帮手（或者用工牌上的「⋯」复制一个）。开工前被拦下的任务显示「没开工」，不算失败，编程助手能重派或撤掉。

**接口报错断在半路的任务**：帮手干到一半遇上模型接口出错（连不上、限流、服务端出错），这个任务不记失败也不丢：帮手去歇着，任务回队列等它，回来后接着上次的对话继续干。同一个任务这样自动续跑最多三次，还不行才记成「中断」，交给你和编程助手定。

**叫停**：正在做的任务，你的编程助手可以撤掉（cancel），盒子把帮手和它这一轮起的所有程序一起停掉。帮手每一轮结束时，它起过还没退的程序（测试窗口、后台脚本）也会被收掉。

**中断的任务**（上次退出或崩溃时没做完的）下次打开首页会问你：接着上次的对话继续做、交给编程助手决定、还是先不管。

**桌面通知**：编程助手在你自己那边的软件里，那边的对话闲着时盒子叫不醒它。所以任务交回、没做成、卡住或等它拿主意时，盒子在桌面右下角弹一条系统通知，提醒你去会话里跟它说一声。不想收就在设置页关掉。

**查额度**：认得三家编程套餐——Kimi Code 会员、智谱 GLM Coding Plan、MiniMax Token Plan（帮手里填了这几家的接口地址就自动选好查法）；别家在帮手的「高级」里选「自定义」，填查询地址和返回里已用百分比的路径。结果在帮手详情和任务页「花了多少」里。

出问题先看顶栏「自检」（点开是逐项检查结果，每项写了怎么办），或自检页（`/doctor`）的「复制诊断信息」（已把路径和密钥打码，贴 issue 前自己再过一眼）。每个版本具体变了什么，看 [`docs/release-0.6.md`](docs/release-0.6.md)。

## 给开发者

命令、概念、接口和目录结构。日常使用不用看这一节。

### 命令速查

每个命令都能加 `--lang zh|en` 换输出语言（不写就跟盒子当前的语言走）。

| 命令 | 作用 |
|---|---|
| `python -m boxbox serve [--port 8878]` | 起核心（HTTP + 看门狗 + SQLite），只监听 127.0.0.1 |
| `python -m boxbox tray [--show] [--port 8878]` | 托盘壳：托盘图标（自己写的 ctypes）+ 内嵌窗口（需 `pip install pywebview`）；双击 exe 等价于 `tray --show` |
| `python -m boxbox mcp --station <帮手> --core <URL>` | MCP stdio 门面：只留给不认 `url` 的客户端手动配置用。盒子给的所有条目都只写 `http://127.0.0.1:8878/mcp?station=<帮手>`，客户端直接连核心，不起子进程 |
| `python -m boxbox doctor [--json] [--no-core]` | 自检：核心 / 数据目录 / 编程助手 / Pi / Git Bash / 模板 |
| `python -m boxbox board` | 帮手一览：每个帮手一行 |
| `python -m boxbox todo` | 编程助手的待办：等确认、卡住、闲着的帮手 |
| `python -m boxbox task <id>` | 看一个任务的全部 |
| `python -m boxbox wait [--timeout 600] [--station 猫猫首领] [--port 8878]` | 等帮手交回任务：有新动静打印一行行（退出码 0），等不到 2，核心没开 3 |
| `python -m boxbox report --task <id> --status done --summary "..."` | 帮手回报（heartbeat / done / blocked / issue）|
| `python -m boxbox assign --station <帮手> --card card.json` | 派一个任务（平时由编程助手调 assign）|
| `python -m boxbox review --task <id> --verdict accept --note "..."` | 确认：accept 或 return（退回重做）|

同端口已有核心在跑时，`tray`（含双击 exe）会直接接上它，不另起核心、也不用自己的 `data/`。

### 概念

| 概念 | 含义 |
|---|---|
| 帮手（station / member）| 一个座位：名字 + 干活方式（用 API key 自动跑 / 会话模式）。代码和接口里座位叫 station，帮手的角色叫 member |
| 编程助手（leader）| 你的 AI 编程助手占的座位：写任务、派活（assign）、确认（review）。可以有好几个，每个只管自己派的任务 |
| 任务（card）| 派活的唯一单位，**自成一体**（帮手的新会话没有旧上下文）：`goal` / `inputs` / `expected_output{kind,path}` / `acceptance{review}` 四个必填，缺了 assign 直接拒收 |
| 自动检查（gates）| 交回后先跑的机器检查（exists / headings / command / commits / json / size），不花用量；任一不过直接退回重做，不经过编程助手。任务上的字段叫 `acceptance.gates` |
| 确认（review）| 谁派活谁确认：自动检查过后由派活的编程助手评审（也可交给你定、或自动检查过就算完成）|
| 干活方式（runner）| 帮手怎么干活：`once`（用 API key 自动跑：盒子用 Pi 为每个任务起一个进程）/ `scheduled`（会话模式：读交换文件领任务）；编程助手是 `manual`（在你的 AI 软件里）|
| 语言 | 界面语言记在设置里的 `ui_lang`（zh / en），没设过时按系统语言定；页面词表在 `boxbox/static/i18n-*.js`，后端词表在 `boxbox/i18n_data/` |

### 页面与接口

页面（都在 `http://127.0.0.1:8878`）：

- `/` 首页（办公室画面）：顶栏 + 整屏办公室；昼夜开关、动态 / 用量按钮、聚会街机都在画布里；点猫看详情和实时动作；**上岗就在这里一步步弹窗口**
- `/board` 任务：帮手（一句话状态）、等你处理的、任务；任务详情里是时间线和交付单；「花了多少」（用量 + 效率）默认收起
- `/stations` 帮手：挂绳工牌（编程助手 + A–F），点工牌改配置，「⋯」里改名、换样子、复制、看详情、删除、怎么派活；「再加一个编程助手」
- `/capabilities` 能力：帮手干活方式的开关、代价、实测、来源和许可
- `/settings` 设置：常用几项、数据和隐私（占用空间、从旧版导入）、高级（提醒节奏、卡住提醒、运行记录怎么记和留多久）、重置所有
- `/doctor` 自检：逐项检查结果、怎么办、复制诊断信息
- `/office` 办公室画面单独页（首页嵌的就是它）

接口（GET 只读；写操作只接受本机同源请求；`/mcp?station=<帮手>` 和 `/rpc/<工具>` 给模型走 JSON-RPC）：

- `/api/meta` 顶栏数据：在跑数、成功率、提醒
- `/api/stations` 每个帮手：状态词、一句话状态、当前任务、分钟、位置
- `/api/stations/live?id=<帮手>` 正在干活的帮手最近的动作（只读当前运行记录的尾部）
- `/api/stations/label`（POST）改显示名
- `/api/stations/detail` 帮手详情（配置不含密钥 + 连接 + 调度记录 + 额度）
- `/api/tasks` 任务板（可加 `?state=` 过滤），每张带排队原因
- `/api/tasks/<id>` 一个任务的全部：任务原文、运行记录、回报原文、实测用量、时间线、交付单
- `/api/todo` 待办：等确认、卡住、退回待定、中断、没开工、失败，闲着的帮手
- `/api/interrupted` 上次退出 / 崩溃时中断的卡（POST `/resume` 接着做、`/dismiss` 先不管）
- `/api/timeline` 最近的运行和事件流水
- `/api/tokens` 实测用量（只记能精确测量的；没有接口的帮手显示「不计」）
- `/api/doctor` 自检结果（JSON；`?text=1` 给可复制的诊断文本）
- `/api/settings` 常用参数（含 `ui_lang` 界面语言）；`/api/providers` 服务商清单（`/refresh` 更新）
- `/api/stations_def` 帮手登记（`stations.json` 的内容）
- `/api/onboard/state` `/api/onboard/progress` 上岗进度（步骤、播过的动画、填了一半的表单；progress 的 POST 合并更新）
- `/api/stations/copy`（POST）复制一个帮手：配置和密钥一起复制，名字自动顺延，占下一个空位
- `/api/stations/delete`（POST）删帮手；正在干活的不带 `confirm` 会先回 busy，带上才中断那个任务
- `/api/reset`（POST）重置所有：清帮手、设置、密钥、任务记录和日志，保留 `data/work`；有任务在跑要先 `force`
- `/api/shutdown`（POST）核心自己收工：和托盘「退出」同一条路（结束在跑的打工进程、关数据库）
- `/api/tmp` 临时文件占多大（`/api/tmp/clean` POST 清理）
- `/api/data` 数据目录占多大、其中运行记录多少（`/api/data/clean` POST 现在压缩结束的卡的记录）
- `/api/efficiency` 效率：近几天每张卡 / 每只猫的用时、轮数、用量（`?days=7`）
- `/api/import_old`（POST）从旧版导入：旧版先退出，这台盒子还没有卡时才能导
- `/api/connectors` 支持的客户端清单；`/api/connectors/snippet` 给某个编程助手生成可手贴的连接片段（Cursor 带一键安装链接，Claude Code / Codex 带安装命令）
- `/api/summon/<帮手>` 「怎么派活」：编程助手给装进它的链接 / 命令和唤醒话；会话模式的帮手给那段话、贴到哪、分几步
- `/api/capabilities` 能力页的数据：每个开关的值、说明、代价、近 30 天实测、许可
- `/api/office` 办公室画面的数据
- `/api/health` 存活检查

### 目录结构

```
boxbox/      核心（app / store / dispatcher / watchdog / tokens / gates / office_feed / scenes）
             facades/（mcp_stdio · cli · http，都是薄壳，不持状态）
             runners/（base · pi：用 API key 自动跑 · scheduled：会话模式读交换文件）
             i18n_data/（后端词表，zh / en 两份）
             static/（首页 · 任务 · 帮手 · 能力 · 上岗 · 设置 · 自检页 + i18n-*.js 页面词表）
             templates/（编程助手 / 帮手的说明模板，每份都有中文和英文两版）
assets/      图标和像素立绘（原创）
office/      办公室画面（/office 与首页内嵌）
static/tabler 离线样式（首页外壳用的 tabler.min.css）
docs/        每个版本的更新说明（release-*.md）
data/        运行时数据：boxbox.db、stations.json、secrets.json、tasks/、logs/（gitignored，不入库；exe 模式下在 exe 旁边）
tmp/         临时文件：每张卡一个子目录，自动清理（gitignored；exe 模式下在 exe 旁边）
```

## 已知限制

- 会话模式：每次来领任务都没有上下文；你那边的定时任务没触发时，盒子只能提醒，拉不起来。
- 编程助手在你那边的软件里，对话闲着时盒子叫不醒它，只能用桌面通知和托盘提醒你。
- 编程助手中途给帮手的留言，要等帮手干完这一轮才送到。
- 用量只有实测：会话模式的帮手和编程助手自己的消耗不计；「省了多少」暂不展示。

另外几条现状：

- exe 是 PyInstaller 打的单文件包，每次启动会先解压到临时目录再运行，个别杀毒软件会误报。
